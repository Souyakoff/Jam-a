🕘 Récemment visités · tout l’historique

⌨️ Raccourcis

  • Ctrl+T nouvel onglet · Ctrl+W fermer
  • Ctrl+L barre d'adresse
  • Ctrl+D ajouter aux favoris
  • Ctrl+H historique · Ctrl+Shift+O favoris
  • F12 outils de développement
  • Ctrl+Shift+M mode mobile

🌱 Tu débutes ?

Fais un clic droit sur une page puis ouvre les outils avec F12 : tu verras le HTML et le CSS qui la composent. Pour apprendre, essaie MDN Learn.

🛠 Pour les devs

Tape localhost:3000 directement dans la barre d'adresse. Le bouton 🧹 vide le cache et les cookies du site ouvert, 📱 simule un écran de téléphone. Ouvre une API JSON : elle s’affiche en arbre lisible.

🛡 Vie privée

Les pubs et les traqueurs sont bloqués par défaut. Aucune télémétrie : tes favoris et ton historique restent sur ton ordinateur, Jam<a n’envoie rien sur toi.
